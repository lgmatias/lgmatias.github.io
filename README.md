# lgmatias.github.io

Personal site of John Matiasevich: security engineer focused on identity and access management and cloud infrastructure. Live at https://lgmatias.github.io.

The site is published as static HTML built from the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme. Pages are edited directly in this repository; there is no Jekyll source or `_config.yml` here.

Pages:

- `index.html`: about, experience, news, certifications
- `projects/`: project cards and write ups
- `404.html`: not found page
